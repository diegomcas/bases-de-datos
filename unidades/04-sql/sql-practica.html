01

Tips Sin palabras …

  • Pero antes unos tips:
  • Usen siempre el ; al final de cada sentencia.
  • 2. Para los UPDATE y DELETE, verifiquen siempre el WHERE antes de ejecutar. ¡Un DELETE sin WHERE borra toda la tabla!
  • 3. Pueden usar SELECT * FROM tabla LIMIT 10; para ver los primeros registros y entender qué columnas tienen.

    Usen MySQL Command Line Client para resolver.

07

Navegación de Datos (LIMIT y Paginación) Cuando tenemos muchos datos, necesitamos mostrarlos en "páginas" para no saturar al usuario.

  • Desafío O (La primera página): Imaginá que en el sistema de "El Chip" queremos mostrar los repuestos de a 2 por vez. Escribí una consulta que devuelva los primeros 2 repuestos de la tabla, ordenados alfabéticamente por nombre.
  • Pista: Usá ORDER BY nombre ASC LIMIT 2.
  • Desafío P (Simulando la Página 2): Ahora necesitamos ver los siguientes 2 repuestos (del 3 al 4). Para esto, debemos decirle al motor que se "saltee" los primeros 5 y tome los 5 siguientes.
  • Consulta: SELECT * FROM repuesto ORDER BY nombre ASC LIMIT 5 OFFSET 5;
  • (En MySQL también podés usar la sintaxis abreviada: LIMIT 5, 5 donde el primer número es cuántos saltar y el segundo cuántos traer).
